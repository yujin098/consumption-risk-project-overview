# 자료를 받은 뒤 분석 범위를 정한 과정

[프로젝트 소개](PROJECT_OVERVIEW.md) → **분석 과정** → [가상데이터 결과](DEMO_RESULTS.md)

실제 대화·기존 코드·로컬 산출물을 바탕으로 판단의 연결을 정리한 문서다.
작성 당시의 일지나 모든 작업을 직접 수행했다는 증명이 아니라, 이해를 위한 재구성이다.
이 문서의 실제 요약 수치와 가상 실행 결과는 서로 다른 자료에서 나온 값이다.

## 1. 자료로 답할 수 있는 질문부터 정했다

초기 구상은 소비 변화로 부실을 감지하고 여신 판단에 연결하는 것이었다.
그러나 자료는 2026년 1~6월의 월·시도·시군구·성별·연령대·업종별 이용금액과 이용건수 집계였다.
한 행은 사업자 한 명의 실적이 아니며, 이용건수도 고객 수가 아니다.

소비 흐름은 볼 수 있지만 개별 차주의 상환능력이나 연체 발생은 확인할 수 없었다.
따라서 목적을 **지역·업종별 소비 약화와 추가 점검 우선순위**로 좁혔다.
자동 한도 산정, 부실 선행 예측, IFRS 9 충당금 최적화는 구현 성과에 포함하지 않는다.

## 2. 감소율보다 먼저 비교 가능성을 확인했다

기간 누락을 소비 감소로 오인하거나 몇 건의 변화로 큰 증감률을 만드는 일을 피하려고
필수 항목·결측·중복·기간·거래량을 점검했다.

| 실제 로컬 분석 구분 | 조합 수 |
| --- | ---: |
| 전체 지역·업종 | 2,379 |
| 6개월 관측 완료 | 2,327 |
| 매월 최소 100건을 충족해 점수 계산 | 2,246 |
| 기간 불완전 | 52 |
| 기간은 완전하나 거래량 기준 미달 | 81 |

100건은 분석상 설정이며 검증된 금융정책 기준이 아니다. 점수에서 제외됐다는 것은
안전하다는 뜻도 아니다. 원본부터 점수까지 재실행한 기록은 로컬에 보관했다.

**현재 공개 예제:** [assess_quality](../src/analysis_workflow.py)는 명시한 분석 기간과
실제 관측 월을 대조하고, 동일 집계 키 중복·유효 값·거래량을 점검한다. 제외 대상도
이유와 함께 남긴다. 이 기능은 공개 예제를 보완한 것이며 위 실제 수치를 새로 재현한 결과는 아니다.

## 3. 금액과 거래 빈도를 나누어 봤다

지역·업종별 월 이용금액과 이용건수를 합산하고 건당 결제금액을 계산했다.
금액이 유지되는데 건수가 줄면 건당 금액은 올라간다. 그 사실만으로 고객 이탈이나
물가 상승을 원인으로 단정하지 않고, 추가 확인할 패턴으로 본다.

**공개 코드:** [build_region_industry_month](../src/features.py).
외부 CPI 보정 함수도 [risk_model.py](../src/risk_model.py)에 있지만, 가상 실행에서는 호출하지 않는다.
현재 CSDI는 `real_amount`가 아니라 `amount`로 계산한 상대변화를 사용한다.
인구·점포·폐업 자료를 결합해 검증했다는 주장은 하지 않는다.

## 4. 공통 흐름과 개별 흐름을 비교했다

특정 지역의 업종이 감소해도 전국 같은 업종이 함께 감소했다면 해석이 달라진다.
지역 전반의 변화도 구분하기 위해 전국 동일 업종과 지역 전체 흐름을 비교 기준으로 추가했다.

이것은 공통 흐름을 고려한 상대 비교다. 계절성·경기 영향을 완전히 제거하거나 원인을
밝히는 방법은 아니다. 실제 분석의 ‘지역 전체’는 제공된 11개 업종의 합계다.
가상 실행에서는 품질점검을 통과한 가상 자료의 합계를 사용한다.
절대 소비가 늘어도 상대적으로 약할 수 있으므로 원래 변화율과 상대변화를 함께 읽는다.

**공개 코드:** [add_national_benchmarks / add_two_way_benchmarks](../src/features.py).
월별 전국 비교는 변화율 차이, 이중 비교와 기간 처음·끝 비교는 성장배율 비율을 사용한다.

## 5. 여러 신호를 점수로 정리하고 설정에 따른 변화를 확인했다

| 구성요소 | 기본 가중치 |
| --- | ---: |
| 금액 상대감소 | 25% |
| 건수 상대감소 | 30% |
| 반복된 금액·건수 동반부진 | 20% |
| 핵심 연령층 결제구성비의 상대변화 | 15% |
| 월별 상대 건수 변화의 변동성 | 10% |

동반부진은 비율을 쓰고, 나머지 신호는 산출 대상 내 백분위로 바꾼다.
가중합에 100을 곱한 값이 CSDI다. 80점이 부도확률 80%를 뜻하지 않는다.

실제 기존 패널에 대한 로컬 감사에서는 동일 가중치로 바꿨을 때 상위 225개 중
193개가 유지되고 32개가 교체됐다. 이 결과는 검토한 설정에서의 순위 안정성을 보여주며,
예측력이나 가중치의 최적성을 입증하지 않는다.

**현재 공개 예제:** [run_analysis](../src/analysis_workflow.py)는 기본·동일 가중치와
최소 거래량 50·100·200건의 6개 조합을 가상자료로 재계산한다.
기본 설정 대비 대상 수, 상위 목록 유지·진입·이탈, 공통 대상의 순위 변화를 출력한다.
그 결과는 [가상데이터 결과 예시](DEMO_RESULTS.md)에서 볼 수 있으며, 위 실제 193개·32개와는 별개다.

K-means 함수는 공개돼 있지만, 단순 규칙보다 추가적인 실무 판단 가치를 입증하지 못해
핵심 발표 본문에서 제외하기로 했다. 비교 기록은 로컬에 보관했다. 가상 실행에는 군집 비교를 넣지 않았다.

## 6. 결과의 끝은 추가 확인이다

제안하는 결과물은 변화 지표·점검 순서·점수 기여·자료 부족 이유를 함께 보여주는 목록이다.
담당자가 계절 행사, 자료 범위, 일시적 변화 등을 더 확인하는 출발점으로 사용한다.

현재 공개 예제는 관측된 조합 중 제외 대상도 CSV에 남긴다. 금융기관 운영 화면이나
차주·대출 자료 연계 기능은 구현하지 않았다. 실제 점검 시간이나 손실 감소 효과도 검증하지 않았다.
