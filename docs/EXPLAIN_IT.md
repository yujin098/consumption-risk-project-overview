# 직접 확인할 계산과 면접 질문

아래 숫자는 실제 데이터가 아닌 설명용 가정이다. 아직 직접 수행한 경험으로 적지
않고, 확인한 뒤 본인이 무엇을 이해하고 수정했는지 기록한다.

## 1. 금액과 건수를 구분하는 이유

가상 사례에서 금액이 100,000원으로 유지되고 건수가 10건에서 8건이 됐다면,
건당 금액은 10,000원에서 12,500원으로 변한다. 금액 변화율은 0%, 건수는 −20%,
건당 금액은 +25%다. 이 사실만으로 고객 두 명이 이탈했다고 말할 수 없는 이유를
설명해 본다. 결제건수는 고객 수와 다르다.

## 2. 비교 기준이 필요한 이유

가상 지역의 금액이 20% 증가하고 같은 업종의 비교 집단이 10% 증가했다면,
변화율 차이는 10%p이고 성장배율 비율은 1.2/1.1−1, 약 9.09%다.
둘을 혼용하지 않는다. `features.py`의 `relative_amount_mom`은 변화율 차이이며,
점수 파일의 기간 비교는 성장배율 비율을 사용한다. 어떤 정의인지 먼저 확인한다.

## 3. 저거래량을 안전으로 보지 않는 이유

관측량이 부족해 점수를 유보하는 것은 위험이 낮다는 판단이 아니다.
가상 실행에서 점수가 비어 있는 대상을 찾아, 왜 0점으로 넣지 않았는지 설명한다.

## 4. 테스트가 확인하는 것

테스트는 인공 입력에서 계산이나 예외 처리가 기대대로 동작하는지 확인한다.
부실을 예측한다는 검증은 아니다. 테스트 하나를 읽고 무엇이 바뀌면 실패해야 하는지
말해 본다. 원본 코드 대신 별도 연습 복사본에서 수정한다.
