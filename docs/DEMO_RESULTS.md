# 가상데이터로 따라가는 소비 점검 분석

이 보고서의 지역·업종·금액·건수·점수는 모두 인공 예제다. 실제 BC카드 분석 결과가 아니다.

생성 명령: `python -m src.synthetic_demo outputs/demo`

분석 기간은 2026년 1~6월로 명시했다. 품질점검 → 기준 비교 → 한 대상의 점수 계산 순서로 읽는다.

## 1. 어떤 대상을 계산하고, 왜 제외했는가

관측된 지역·업종 14개 중 기본 기준에서 11개에 점수를 계산했다. 제외 대상도 아래 표와 점수 파일에 남긴다.

| 가상구1 | 90001 | 6 | 425 |  |
| 가상구1 | 90002 | 6 | 372 |  |
| 가상구1 | 90003 | 6 | 319 |  |
| 가상구2 | 90001 | 6 | 425 |  |
| 가상구2 | 90002 | 6 | 425 |  |

## 2. 기준을 바꾸면 무엇이 달라지는가

`baseline`: 금액 25%·건수 30%·동반부진 20%·연령 구성비 15%·변동성 10%. `equal`: 다섯 항목에 각각 20%. 이름 뒤 숫자는 매월 최소 거래 건수다.

| 설정 | 산출 대상 | 상위 3 유지 | 진입 | 이탈 | 공통 대상 평균 순위 변화 |
| --- | --- | --- | --- | --- | --- |
| baseline_100 | 11 | 3 | 0 | 0 | 0.0000 |
| equal_100 | 11 | 3 | 0 | 0 | 0.5455 |
| baseline_50 | 11 | 3 | 0 | 0 | 0.0000 |
| equal_50 | 11 | 3 | 0 | 0 | 0.5455 |
| baseline_200 | 10 | 3 | 0 | 0 | 0.3000 |
| equal_200 | 10 | 3 | 0 | 0 | 0.8000 |

모든 비교의 기준은 `baseline_100`이다. 상위 목록의 동점은 지역·업종 키 순서로 정리한다. 순위는 동점에 같은 최상위 순위를 부여한다. 거래량 기준을 바꾸면 대상과 백분위 기준 분포도 함께 바뀐다. 가중치 비교는 같은 대상 안의 비중만 바꾼다. 목록 유지율은 예측력이나 최적성의 증거가 아니다.

## 3. 한 대상의 점수 따라가기

기본 설정에서 점수가 가장 높은 **가상구4 · 업종 90001**를 예제로 골랐다.

### 월별 입력을 먼저 확인

| 월 | 금액 | 건수 | 건당 금액 |
| --- | --- | --- | --- |
| 2026-01 | 4250000 | 425 | 10000.0000 |
| 2026-02 | 4570000 | 457 | 10000.0000 |
| 2026-03 | 4890000 | 489 | 10000.0000 |
| 2026-04 | 5200000 | 520 | 10000.0000 |
| 2026-05 | 5520000 | 552 | 10000.0000 |
| 2026-06 | 5850000 | 585 | 10000.0000 |

건당 금액 = 이용금액 ÷ 이용건수. 이용건수는 고객 수가 아니다.

### 기간 처음과 끝의 상대변화를 계산

금액 변화율 = 5850000 ÷ 4250000 − 1 = 0.376471

전국 동일 업종 성장배율 = 1.187647

지역 상대 성장배율 = 지역 전체 성장배율 ÷ 입력 전체 성장배율 = 1.219158

이중 상대 금액 변화 = (5850000 ÷ 4250000) ÷ 1.187647 ÷ 1.219158 − 1 = -0.049353

절대 금액이 증가했어도 비교 집단보다 성장 폭이 작으면 상대변화는 음수가 될 수 있다. 이 예제의 높은 점수를 실제 매출 감소나 부실로 해석하면 안 된다.

같은 방식으로 건수 상대변화를 계산한다. 월별 상대변화로 반복 부진과 변동성을 계산하며, 연령 구성비는 업종별 첫 달 최다 결제 연령층을 기준으로 처음과 끝을 비교한다.

| 점수 입력 | 값 |
| --- | --- |
| 금액 이중 상대변화 | -0.0494 |
| 건수 이중 상대변화 | -0.0605 |
| 월별 금액·건수 동반부진 비율 | 1.0000 |
| 핵심 연령 구성비의 상대변화 | 0.0001 |
| 월별 상대 건수 변화의 표준편차 | 0.0015 |

### 구성요소를 합쳐 최종 점수를 계산

금액·건수·연령 변화는 부호를 뒤집고, 변동성은 그대로 산출 대상 내 백분위로 바꾼다. 동반부진은 관측 변화 구간의 비율을 사용한다. 백분위는 전체 비교 대상이 있어야 계산할 수 있다.

| 구성요소 | 정규화 값 | 가중치 | 점수 기여 |
| --- | --- | --- | --- |
| amount_stress | 1.0000 | 0.2500 | 25.0000 |
| transaction_stress | 1.0000 | 0.3000 | 30.0000 |
| persistence_stress | 1.0000 | 0.2000 | 20.0000 |
| demographic_stress | 0.3636 | 0.1500 | 5.4545 |
| volatility_stress | 0.7273 | 0.1000 | 7.2727 |

각 기여 = 정규화 값 × 가중치 × 100. 합계 **87.7273점**. 표시는 반올림했으며 계산은 원래 정밀도를 사용한다. 점수는 부도확률이 아니다.
