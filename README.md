# 소비데이터 분석 과정을 설명하는 코드 예제

소비 변화에서 추가 점검할 대상을 정리하려는 프로젝트의 구현 과정을 보여주는
가상데이터 예제입니다. 여신전략·신용정책·리스크기획·리스크관리 관점에서
자료의 의미, 비교 기준, 판단의 한계를 설명하는 데 초점을 둡니다.

**실제 데이터가 아닌 가상데이터로 실행하는 코드 예제입니다.**
원본 공모전 데이터와 발표자료는 포함하지 않습니다. 아래 분석 과정 문서에는 실제 자료의 요약 통계와 분석 결과 일부가 포함됩니다.

## 어떤 문제를 다루는가

소비가 감소했다는 사실을 바로 차주의 부실로 해석할 수는 없습니다.
비교 대상의 공통 흐름, 거래 빈도, 자료가 충분한지를 함께 살펴볼 필요가 있습니다.
그래서 이 예제는 입력 표준화부터 비교 지표와 점수 유보까지의 처리 흐름을 보여줍니다.
자동 여신 결정이나 부실 예측 시스템은 아닙니다.


## 프로젝트 소개와 분석 과정

1. [프로젝트 소개](docs/PROJECT_OVERVIEW.md): 목적, 접근 방식, 본인 역할과 AI 활용
2. [분석 과정](docs/ANALYSIS_STORY.md): 분석 범위를 좁힌 이유, 비교 기준, 점수 해석과 한계
3. 아래 실행 방법과 코드 읽는 순서에 따라 가상데이터 예제를 확인합니다.

분석 과정의 요약 통계는 실제 자료에서 계산한 값입니다. 아래 코드 실행용 가상데이터와 구분해서 읽어 주세요.

## 실행 방법

Python 3.12에서 실행합니다. 이 폴더를 작업 위치로 지정하세요.

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.synthetic_demo outputs/demo
```

`outputs/demo`는 새 경로여야 합니다. 이미 있다면 다른 폴더명을 지정합니다.
명령은 가상 입력을 생성하며 실제 파일·외부 API를 읽지 않습니다.
가상 입력, 월별 지표, 점수 표, 가상자료 안내문을 출력합니다.
점수 산출 대상과 저거래량 점수 유보 사례를 모두 포함합니다.
이는 기능 설명용 데이터이며 실제 분포를 모사하거나 예측력을 검증하지 않습니다.

## 읽는 순서와 판단 이유

| 순서 | 코드 | 확인할 내용 |
|---|---|---|
| 1 | [입력 검증](src/normalize_data.py) | 필수 항목과 날짜를 확인하고 음수 건수를 거부하는 이유 |
| 2 | [지표 계산](src/features.py) | 금액·건수·건당 금액을 구분하고 비교 기준을 적용하는 방법 |
| 3 | [점수 계산](src/risk_model.py) | 구성요소를 합산하고 저거래량 대상의 점수를 유보하는 방법 |
| 4 | [가상 실행](src/synthetic_demo.py) | 위 함수를 연결하는 실행 흐름 |
| 5 | [테스트](tests/) | 작은 인공 입력에서 계산·오류 처리·출력을 확인하는 방법 |

점수 파일에는 CPI·K-means 보조 함수도 남아 있으나 가상 실행에서는 호출하지 않습니다.
군집 사용을 금융 분석 성과로 내세우지 않습니다.

## 한계와 미완성 부분

- `risk_tier` 등의 명칭은 코드상 분류명이지 검증된 신용등급이 아닙니다.
- 가중치와 경계값은 분석상 설정이며 최적성이나 금융 효과를 입증하지 않았습니다.
- 입력 검증은 모든 오류를 처리하는 수준이 아닙니다. 금액·건수의 비수치값,
  0으로 나누기, 월 중간 누락, 전체 유효 대상 부재 등의 경계조건 보강이 필요합니다.
- 예제에서 비교 기준의 ‘전국’은 입력에 포함된 가상 지역의 합계입니다.
- 일부 단위 테스트의 실재 지명은 식별용 문자열이며 숫자는 인공 계산 예제입니다.
- 테스트 통과는 실제 금융 예측력이나 운영 적합성의 증명이 아닙니다.

## 본인 역할과 AI 활용

본인은 직무 관점의 목적을 정하고, 과장된 주장을 제외하며, 선택 이유가 드러나도록
방향을 조정했습니다. 코드 작성·실행과 문서 초안에는 AI가 사용됐습니다.
직접 작성하지 않은 코드를 모두 본인 개발 성과로 소개하지 않습니다.
[직접 확인할 계산과 질문](docs/EXPLAIN_IT.md)을 검토하고 수행한 범위를 기록합니다.

이 예제는 실제 결과물을 대신 공개하는 자료가 아닙니다. 기존 AI 데이터 처리의
허용 여부나 후속 조치 문제를 해소하는 자료도 아닙니다.
